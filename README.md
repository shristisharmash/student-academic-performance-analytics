## 📌 Project Overview

This project analyzes student academic performance using data on examination scores, attendance, study habits, academic satisfaction, motivation, and other student-related factors.

The goal is to identify patterns and relationships between academic performance and different academic and behavioral variables.

---

## 🎯 Objectives

- Analyze student academic performance
- Examine the relationship between attendance and performance
- Analyze study habits and consistency
- Explore student satisfaction and academic confidence
- Identify important patterns using data analysis
- Present findings through tables, Pivot Tables, KPIs, and dashboards

## 📁 Dataset

| Variable | Description |
|---|---|
| Institution | Student's institution |
| Field of Study | Academic discipline |
| Year of Study | Current year of study |
| City | Student's city |
| Recent Exam Percentage | Score in the most recent exam |
| Average Class Attendance | Typical attendance level |
| Satisfaction with Academic Performance | Self-reported satisfaction |
| Confidence in Ability to Perform Well | Self-reported confidence |
| Study Routine Consistency | How consistent the study routine is |
| Subject Understanding | Self-reported understanding of subjects |
| Study Motivation | Motivation level for studying |
| Study Management | Ability to manage study time and tasks |
| Study Focus | Level of focus while studying |
| Attendance Contribution to Academics | Perceived effect of attendance on academics |

## 🔎 Analysis Performed

### 1. Data Cleaning
- Cleaned academic performance scores
- Standardized percentage/score values
- Prepared attendance data for analysis
- Checked and organized categorical variables

### 2. Descriptive Analysis
- Calculated average academic performance
- Analyzed average attendance
- Examined study-related variables
- Compared academic performance across different categories

### 3. Pivot Table Analysis
Pivot Tables were created to analyze:
- Academic performance
- Attendance
- Study routine consistency
- Academic satisfaction
- Other student characteristics

### 4. Dashboard
An Excel dashboard was developed to give a summarized view of the dataset using KPIs, tables, and visualizations.
